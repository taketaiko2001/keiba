# keiba - 競馬仮想馬券シミュレーション記録

このリポジトリは、実際の金銭を伴わない**仮想の馬券購入シミュレーション**の記録用です。
原資100万円 → 目標120万円（1レースあたり仮想投資上限5,000円）を、JRA・地方競馬のレースを対象に運用します。

- **実際の馬券購入・送金は一切行いません。** すべて記録上のシミュレーションです。
- 記録は [`競馬運用記録.md`](./競馬運用記録.md) に集約します。運用ルール、収支サマリー、レースごとの買い目・結果・反省をここに追記していきます。
- このリポジトリはクラウド定期ルーティン（RemoteTrigger）から定期的にチェックアウトされ、以下を行います。
  1. 直近数時間以内に発走予定のJRA・地方競馬レースを確認する
  2. 発走1時間以上前のレースのうち、オッズ等から見て妙味があると判断できるものがあれば、仮想の買い目を確定し記録に追記する
  3. 過去に「仮想購入」したレースで結果がまだ未確定のものがあれば、Web検索で結果を取得し、着順・払戻・収支・反省を記録に反映する
  4. 変更をコミットしてpushする
